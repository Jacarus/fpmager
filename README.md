# FP-Mager

FP-Mager is a first-person shooter game being developed using the Godot game engine. This repository contains the source code and assets for the game. The project aims to create an engaging FPS experience with modern graphics and gameplay mechanics.

## Features

- First-person perspective gameplay
- Modern graphics and visual effects
- Dynamic lighting and shadows
- Smooth character movement and animations
- Weapon systems with various firemodes
- Interactive environment elements
- Audio system with sound effects and music
- User interface with menus and HUD
- Physics-based interactions
- Multiplayer support (planned)
- Cross-platform compatibility

## Project Structure

```
fp-mager/
├── scenes/          # Godot scene files
├── scripts/         # GDScript files
├── assets/          # Game assets (textures, models, sounds, etc.)
├── export_presets.cfg  # Export presets
├── icon.png         # Game icon
├── README.md        # This file
└── project.godot    # Godot project file
```

## Getting Started

### Prerequisites

To run this project, you'll need:
- Godot Engine 4.0 or later (free and open-source)
- Basic understanding of Godot game engine
- Visual Studio Code or another code editor (optional but recommended)

### Installation

1. Clone the repository:
   ```
   git clone https://github.com/your-username/fp-mager.git
   ```

2. Open the project in Godot Engine:
   - Launch Godot Engine
   - Click "Open" and navigate to the project folder
   - Select `project.godot` file

3. Run the game:
   - Press the "Play" button in Godot editor, or
   - Press F5 to start the game in the editor
